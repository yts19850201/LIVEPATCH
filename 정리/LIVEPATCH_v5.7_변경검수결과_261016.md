2026-10-16 기준. 기획 원본 9개 파일을 정합화했고 수정 전 파일을 초기에는 `수정전백업_261016`에 보존했다. 2026-10-21 폴더 정리 후에는 작업 폴더의 `../보관_261021/LIVEPATCH_이전작업보관_261021.zip`에서 복구할 수 있다. 현재 정본은 마스터 27장과 JSON의 `release_current`다. 기존 파일명은 참조 호환성을 위해 유지하고 내부 버전을 v5.7로 갱신했다.

## 현재 MVP 범위

- 폐쇄형 베타: 36페이지+17공용 오버레이. 테스트 크레딧 사용, 실결제 없음.
- 유료 MVP: 베타에 결제 관련 8페이지+2오버레이 추가, 총 44페이지+19오버레이.
- 제품: 고객 1인·사이트 1개, 단일 요소 문구·기존 이미지·허용 스타일, 음성/터치 요청, 미리보기·검증·승인·반영·복원.
- 현재 지원 범위 밖의 변경은 실행하지 않고 이유와 연결/지원 안내를 제공한다. 전문가 판매는 최초 MVP에서 제외한다.

## 검수 결과

- 화면 ID 173개, 필드 1,174개. 화면 ID 및 화면 내 필드 key 중복 없음.
- JSON actions 참조 누락 없음. primary_action은 actions에 포함되거나 상태별 정의 대상으로 비워 둠.
- 마스터와 단독 필드 상세명세의 19~22장 본문 일치.
- 마스터 MD·HTML 이미지 참조 579건, 상세명세 참조 173건의 파일 누락 없음.
- 브라우저 검사에서 마스터 내부 앵커 누락 0, 깨진 이미지 0, 페이지 실행 오류 0.
- 목업 필터: 현재 MVP 63개, 내부 통합 58개, 후속 52개. 템플릿 173개 보존. C13의 주요 행동은 ‘말로 바꾸기’로 표시.
- 통합 HTML의 첫 화면을 시각 확인했다. 제품 전체 화면의 디자인·사용성·접근성 검수가 완료된 것은 아니다.

## 남은 출시 차단 항목

TBD는 **383개**이며, 현재 출시 및 내부 통합 범위에는 **271개**가 포함된다. 디자인 샘플을 일부 보완했으나 실제 API·정책을 임의로 확정하지 않았다. `API_SCHEMA_REF` 148개도 OpenAPI example 구현 완료를 의미하지 않는다. 현재 계약 준비 상태는 `DRAFT_NOT_DEV_READY`다.

STT/PG 공급사, 한국어 인식·음성 처리 정책, 가격·원가 한도, 스냅샷 보존·개인정보·환불 정책, OpenAPI·오류·권한 상세, 실제 구현 공수는 출시 게이트에서 확정해야 한다. 가격 9,900원·100C 및 하루 생성 10회는 현재 작업 기준값이며 검증된 상용 실적이 아니다.

기존 PNG 221개는 v5.6-r2 참고 스냅샷으로 보존했다. 새 정책과 최종 디자인은 이후 Figma 작업에서 반영한다. 이번 검수는 실행 가능한 LIVEPATCH 제품의 테스트나 배포 검증이 아니다.

## Figma 확인

[LIVEPATCH 작업 파일](https://www.figma.com/design/VwuyN75CQK9Kn0ZyIVmF4S/LIVEPATCH?node-id=0-1)의 메타데이터에 접근했다. `0:1` 페이지 이름은 `LIVEPATH_ver1.0`이며 조회된 하위 디자인 요소는 없다. 쓰기 권한을 검증하거나 캔버스·페이지 이름을 변경하지 않았다.
