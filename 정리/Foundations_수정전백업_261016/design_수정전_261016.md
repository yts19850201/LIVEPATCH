# Project Design Brief

> 이 문서는 프로젝트마다 복사해 사용하는 실행용 디자인 브리프입니다.
> `docs/style.md`는 장기적인 개인 취향, 이 문서는 현재 프로젝트의 구체적인 결정을 담당합니다.
> Codex는 URL 분석 후 이 문서를 먼저 업데이트하고 디자인 또는 구현을 시작합니다.

## 1. 프로젝트 기본 정보

- 프로젝트명: `[입력]`
- 페이지명: `[메인 / 소개 / 상세 / 목록 등]`
- 서비스 한 문장 설명: `[입력]`
- 주요 사용자: `[입력]`
- 사용자가 이 페이지에서 해야 할 핵심 행동: `[입력]`
- 페이지가 해결해야 할 문제: `[입력]`
- 구현 환경: `[React / Next.js / Vue / HTML 등]`
- Figma 출력 필요 여부: `[예 / 아니오]`
- Figma 메인 시안 기본값: PC 화면만 우선 생성하고, 모바일·태블릿은 별도 요청 시에만 생성합니다. PC 화면 폭은 1920px, 콘텐츠 폭은 1440px 중앙 정렬을 기본으로 하며, 사용자 지정값이 있으면 우선 적용합니다.
- Figma 레이아웃 원칙: 디자인 파일 생성·수정 시 Auto Layout 기반으로 우선 구성합니다. 구조상 불가피한 겹침·자유 배치 요소에만 absolute를 사용하며, 세부 기준은 `docs/style.md`의 「Figma 디자인 파일의 Auto Layout 우선 원칙」을 따릅니다.

전체 양식을 한 번에 채우기보다 다음 5가지를 먼저 정합니다. 현재는 모두 미확정이며 실제 제작 요청에서 제공된 정보부터 반영합니다.

| 항목 | 현재 값 |
|---|---|
| 서비스명과 한 문장 설명 | 미확정 |

### 섹션 리듬 규칙

- 같은 카드 그리드를 2개 섹션 이상 연속 사용하지 않습니다.
- 콘텐츠가 충분한 다중 섹션 메인 페이지는 3개 이상의 정보 구성 방식을 우선 검토합니다. 짧은 랜딩, 단일 기능 화면, 승인된 Figma 구현에서는 목적·콘텐츠 양·구현 정확도를 우선하며, 형식의 수를 맞추려고 섹션을 추가하지 않습니다.
- 배경색 변경만으로 섹션을 구분하지 않습니다.
- 가장 중요한 섹션이 페이지 중간에서 묻히지 않도록 크기와 위치를 조절합니다.

## 16. 최종 검수 기준

이 표를 프로젝트 평가의 단일 기준으로 사용합니다. Quick Task는 전체 점수 평가 대신 수정 요소와 영향 범위만 확인합니다.

| 항목 | 배점 | 평점(0~10) 또는 N/A | 확인 근거·화면 위치·수정 내용 |
|---|---:|---|---|
| 프로젝트 고유성 | 15 |  |  |
| 참고 사이트 재해석 | 10 |  |  |
| 정보 구조와 탐색성 | 15 |  |  |
| 한국어 타이포그래피 | 10 |  |  |
| 레이아웃 리듬 | 10 |  |  |
| 색상 완성도와 일관성 | 10 |  |  |
| 실제 콘텐츠 대응 | 10 |  |  |
| Figma 편집 가능성 | 10 |  |  |
| 반응형 완성도 | 5 |  |  |
| 접근성과 상태 설계 | 5 |  |  |
| **기본 배점 합계** | **100** |  |  |

- 각 적용 항목의 평점은 0~10점으로 기록합니다. 획득점수는 `배점 × 평점 ÷ 10`입니다.
- 최종 점수는 `적용 항목 획득점수 합 ÷ 적용 항목 배점 합 × 100`으로 환산합니다.
- Figma 생성·수정이 없는 코드 전용 작업은 ‘Figma 편집 가능성’을 N/A로 제외합니다. 그 밖의 비적용 항목도 사유를 기록한 뒤 분모에서 제외합니다. 예: 참고 사이트가 없으면 ‘참고 사이트 재해석’은 N/A입니다.
- 통과 기준은 환산 점수 80점 이상이면서 모든 적용 항목의 평점이 8점 이상인 경우입니다. 8점 미만 항목은 수정하고 해당 범위를 재검토합니다.
- 미검증은 N/A나 통과가 아닙니다. 미검증 사유와 남은 확인 사항을 보고하고 검수 완료로 표시하지 않습니다.
- 점수는 판단 보조 수단입니다. 핵심 행동 불능, 콘텐츠 누락, 화면 잘림, 키보드 조작 불가 등 핵심 오류는 점수와 관계없이 수정합니다.
- Figma 메인 시안은 기본 PC 1920px·콘텐츠 1440px에서 검토하고, 모바일·태블릿은 별도 요청 시에만 생성·검토합니다. 웹 반응형 구현은 1440px / 1280px / 768px / 390px에서 실제 콘텐츠로 확인하고, 검토한 화면·근거를 기록합니다. Figma 시안은 시각·상태 설계를 확인하고 실제 키보드 동작 등 런타임 검증은 구현 단계의 남은 항목으로 구분합니다.
