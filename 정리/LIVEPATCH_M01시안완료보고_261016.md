# LIVEPATCH 공식 웹 메인 시안

## 결과

- 위치: 기존 `LIVEPATH_ver1.0` 페이지(0:1). 페이지 이름 유지.
- 단일 프레임: M01 LIVEPATCH 공식 웹 메인 PC 1920 261016, 1920×2656px.
- 콘텐츠: 중앙 1440px, 좌우 240px. 모바일·태블릿 시안 없음.
- 구성: Header → 메시지와 제품 시연 → 지원 범위 → 수정 작업 → 반영 과정 → FAQ → 체험 CTA → Footer.
- 핵심 메시지: 홈페이지 수정, 이제 말로 하세요. 주요 행동: 데모로 바로 해보기.
- 제품 시연은 오후공방이라는 한국어 샘플이며, 번호 선택·음성 요청·의도 확인을 편집 가능한 레이어로 표현했다.
- 가격 확정치·고객 수·성능 실적·실제 배포 완료를 주장하는 요소는 추가하지 않았다.

## 재사용과 범위

LP Foundations 변수·텍스트/효과 스타일을 사용하고, Simple Design System의 Mic·Arrow right 아이콘을 재사용했다. M01에 필요한 기본 버튼 3종과 작업 목록·FAQ·번호 요소만 로컬 컴포넌트로 제작했다. 원본 컴포넌트는 Foundations 페이지의 별도 영역에 두고 메인 화면에는 인스턴스를 배치했다.

이 작업은 사용자가 추가 지정한 메인 화면 한 개의 시안이다. 전체 Components 단계·Studio 화면 제작이나 사용자 디자인 승인 완료를 의미하지 않는다. 실행 가능한 웹사이트나 클릭 프로토타입 구현은 이번 범위에 포함하지 않는다.

## 검수

- 요청 페이지의 최상위 화면은 M01 프레임 1개.
- 프레임 48개 전부 Auto Layout, 텍스트 76개 전부 Pretendard 및 공유 텍스트 스타일 적용.
- 인스턴스 23개, 벡터 5개. 전체 UI를 담은 래스터 이미지나 이미지 채우기 없음.
- 부모 경계 초과·잘못된 폰트·텍스트 스타일 누락·레이어 이름의 `/` 없음.
- 전체 페이지 렌더링에서 문구·위계·간격·시연 배치를 확인했다.
- 실제 키보드·음성·권한·반영 동작과 반응형 구현은 아직 검수하지 않았다.
