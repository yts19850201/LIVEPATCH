# C01·C02 reference 레이아웃 반영

- 대상: Figma LIVEPATCH, 페이지 21:60.
- 참조: 02 design reference의 C13 사용자 Studio(23:43).
- 전폭 상단 탐색 68px, 좌측 메뉴 176px, 중앙 작업 영역 1328px, 우측 보조 패널 416px로 재배치.
- C01 연결 후: 사이트 미리보기와 하단 수정 시작 영역 추가. 높이 1544px.
- C01 연결 전: 연결 후 미리보기 위치를 안내하는 빈 상태. 높이 1160px.
- C02: 기본 정보 첫 화면만 유지. 중앙 입력과 우측 연결 요약·안내를 분리. 높이 1080px.
- 기존 텍스트 ID·내용 보존 검사 통과. 메뉴 7개, 버튼과 테마 전환 프로토타입 유지.
- PC 본문 16px, 좌측 하단 해·달 아이콘 44px 클릭 영역 유지.
- Auto Layout으로 구성. 시연 사이트 인스턴스의 기존 선택 테두리·배지는 숨김.
- 라이트 프레임 행을 y=1864로 이동하여 늘어난 C01과의 겹침 방지.
- HTML 원본은 수정하지 않음.

프레임: C01 70:1886·70:2025, C02 70:2164·70:2317, 연결 전 72:1314·72:1450.

## 치수·공통 영역 추가 검수

- 6개 프레임의 콘텐츠 내부 폭 1272px, 좌측 메뉴 176px, 보조 패널 416px 통일.
- 상단 68px를 제외한 좌측·중앙·우측 영역의 높이를 일치시킴.
- C02 단계 표시 텍스트의 고정 200px 폭을 가변 폭으로 변경해 넘침 해결.
- C02 입력 패널 고정 높이를 내용에 맞게 변경하고 불필요한 215px 여백을 24px로 축소.
- 사이트 이름은 가변 폭으로 바꾸고 연결 상태 배지를 우측 끝에 정렬.
- 공통 하단 영역을 Studio 버튼·테마 아이콘·지원 안내로 통일. 연결 전과 C02에는 Studio 버튼을 비활성 상태로 표시하고 기존 연결 이어서 하기 버튼은 보존.
- Studio 버튼 폭 152px, 테마 클릭 영역 44×44px, 공통 하단 높이 194px.
- 기존 본문 텍스트 보존 및 메뉴 7개 유지 확인. 테마 전환 링크 유지.
- 시연 사이트 인스턴스 내부를 제외한 6개 화면의 콘텐츠·패딩 넘침 0건. C01 나이트 및 C02 양쪽 테마 렌더 확인 완료.

## 오른쪽 잘림 수정 및 최종 스타일

- 안내 문구를 고정 폭에서 FILL로 변경. 수정 시작 영역 폭 960·1120·1272px에서 버튼 우측 여백 25px 유지 확인.
- 사이트 정보·수정 시작 박스는 기존 외부 프레임 ID를 유지하면서 내부 Auto Layout을 새로 구성. 구분선도 새 컨테이너로 교체.
- 박스·사이트 미리보기·구분선의 내부 폭 1272px, 시작점 x=28px, 우측 끝 x=1300px로 정렬.
- 상위 콘텐츠와 박스의 클리핑을 해제하고 라이트 콘텐츠 전체 및 나이트 전체 렌더로 경계 확인.
- 우측 패널 배경을 사용자 작업 영역·본문에도 이어서 채우고 중앙 작업 영역은 기본 배경을 유지하도록 수정.
- 우측 패널 끝 위치: C01 연결 후 1544px, C02 첫 화면 1080px, C01 연결 전 1160px로 각 화면 하단과 일치.
- 요청에 따라 내부 버튼·박스에 15px 모서리를 적용했다가 해당 변경만 취소. 최종 상태는 기존 모서리 값이며 우측 패널 배경 수정은 유지.
- 이번 Git 커밋에는 로컬 작업 기록을 저장한다. 실제 디자인 변경은 연결된 Figma 파일에 저장되어 있으며 이 Markdown은 Figma 원본 파일의 내보내기나 복구용 백업이 아니다.
